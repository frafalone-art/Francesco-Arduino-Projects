# 📏 Distance Reactive LEDs

Ultrasonic distance monitoring system with visual LED feedback.

---

## ✨ Features
* Real-time distance measurement
* LED activation based on object distance
* Sensor-driven visual feedback

---

## 🛠️ Hardware
* Arduino board
* Ultrasonic sensor
* LEDs
* Resistors
